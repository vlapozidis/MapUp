🎧 Πριν φτάσει το πρώτο πραγματικό ticket στην ουρά σου, υπάρχει μια μικρή λίστα εργαλείων που αξίζει να εξοικειωθείς. Τίποτα περίπλοκο εδώ — είναι κυρίως να ξέρεις πού βρίσκεται το καθένα.

## Γιατί έχει σημασία τώρα

Κάθε ticket που θα δουλέψεις ξεκινά και τελειώνει στα ίδια λίγα εργαλεία. Εξοικειωθείς μαζί τους τώρα, και η πρώτη σου πραγματική επαφή με πελάτη θα είναι για τον *πελάτη*, όχι για το ποιο κουμπί κάνει τι.

## 🧰 Τι να στήσεις

- **Helpdesk / ticketing software** — εδώ ζει κάθε support ticket, από τη στιγμή που ανοίγει μέχρι τη στιγμή που κλείνει. Επιβεβαίωσε ότι έχεις access και ξόδεψε λίγα λεπτά κάνοντας απλά κλικ παντού πριν σου ανατεθεί κάτι πραγματικό.
- **Knowledge base** — η αναζητήσιμη βιβλιοθήκη άρθρων που χρησιμοποιούν και agents και πελάτες. Ζήτα read access από νωρίς, και ρώτα για write access μόλις νιώσεις άνετα — κάποια στιγμή θα είσαι εσύ αυτός/ή που θα προσθέτει σε αυτό.
- **Screen sharing tools** — για να βλέπεις live την οθόνη ενός πελάτη αντί να μαντεύεις από μια γραπτή περιγραφή. Κάποια bugs είναι σχεδόν αδύνατο να περιγραφούν με λόγια, αλλά εντελώς προφανή τη στιγμή που βλέπεις πραγματικά την οθόνη. Ένας κανόνας ευγένειας που έχει σημασία εδώ: ρώτα πάντα πριν ξεκινήσεις ένα session — είναι η οθόνη κάποιου άλλου.
- **Company chat tool** — για γρήγορες εσωτερικές ερωτήσεις αντί να στείλεις email και να περιμένεις. Ιδανικό για ερωτήσεις τύπου "έχει ξαναδεί κανείς αυτό το error;".

## 🏷️ Τι θα χρησιμοποιείς

`Helpdesk Software` `Knowledge Base` `Screen Sharing` `Company Chat`

## 💡 Συμβουλές

- Ψάξε στο knowledge base *πριν* το χρειαστείς για ένα πραγματικό ticket — το να ξέρεις χοντρικά τι υπάρχει εκεί είναι η μισή αξία.
- Αν δεν είσαι σίγουρος/η αν πρέπει να ξεκινήσεις screen share, απλά ρώτα. Οι πελάτες σχεδόν πάντα λένε ναι, και το να ρωτήσεις χτίζει εμπιστοσύνη σε κάθε περίπτωση.
- Κάνε bookmark το helpdesk και το knowledge base τώρα — θα τα έχεις ανοιχτά όλη μέρα, κάθε μέρα.
