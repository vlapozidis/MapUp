🛠️ This is it — the certification path where "learning about databases" turns into "actually being a DBA."

## Why this is the big one

AZ-900 and DP-900 gave you the vocabulary. DP-300 gives you the day-to-day skillset: the things you'll actually be doing (or fixing) once you're on a real team.

## 🧠 What you'll learn

- **Performance monitoring and tuning** — finding the slow query before it finds you
- **Security and access control** — who can see what, and how to enforce it (RBAC, auditing, encryption)
- **Backups and disaster recovery** — because "we didn't have a backup" should never be a sentence anyone says
- **High availability (HADR)** — keeping databases up even when hardware, zones, or regions have a bad day
- **Routine maintenance** — index maintenance, statistics updates, and the unglamorous work that prevents 2am pages

## 🏷️ Skills you'll pick up

`Performance Tuning` `Security & RBAC` `Backups` `HADR` `Maintenance Plans`

## 📚 How to work through it

1. Open the **DP-300: Administering Microsoft Azure SQL Solutions** learning path on Microsoft Learn.
2. This path is meatier than the first two — budget more time, and don't try to do it all in one sitting.
3. Every time a module mentions a tool (SSMS, Query Store, Azure Monitor), make a mental note — you'll be using it for real very soon in the [hands-on environment](/guides/hands-on).

## 💡 Tips

- HADR (High Availability / Disaster Recovery) can feel like a lot of acronyms at once. Focus on the *why* first: "what happens if this server disappears right now?" The *how* gets much easier once the *why* clicks.
- Security topics here aren't just theory — RBAC and least-privilege access are things you'll configure in your very first real environment.
- 🙋 Genuinely stuck on a concept? This is the module where it's completely normal to ask a senior DBA to walk through it with you.

Next up: put it into practice in your [Hands-On Environment](/guides/hands-on) 🚀
