🌥️ Welcome to your first real Microsoft Learn path! AZ-900 is the on-ramp every cloud role starts from — DBAs included.

## Why this one comes first

Before you can administer a database *in the cloud*, you need to understand the cloud itself. AZ-900 answers the "what is all this, actually?" questions so the rest of your training makes sense.

## 🧠 What you'll learn

- **Core cloud concepts** — the difference between IaaS, PaaS, and SaaS, and why it matters which one you're using
- **Core Azure services** — compute, storage, networking, and databases at a glance
- **Pricing & support** — how Azure billing works and where to find help
- **Governance & compliance basics** — the guardrails that keep cloud environments safe and tidy

## 🏷️ Skills you'll pick up

`IaaS` `PaaS` `SaaS` `Cloud Economics` `Azure Portal`

## 📚 How to work through it

1. Open the **AZ-900: Microsoft Azure Fundamentals** learning path on [Microsoft Learn](https://learn.microsoft.com/) with the personal account you just set up.
2. Work through the modules in order — each one builds on the last.
3. Don't rush the knowledge checks. Getting a question wrong is exactly how the material sticks.

## 💡 Tips

- This path is intentionally broad rather than deep — you're building vocabulary, not mastery, yet.
- If a term feels fuzzy (looking at you, "availability zones"), that's completely normal. It'll click once you see it in the Azure Portal for real during the [hands-on step](/guides/hands-on).
- Feeling confident? Great sign — DP-900 builds directly on this.
