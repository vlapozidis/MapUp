🎧 Before the first real ticket lands in your queue, there's a short list of tools worth getting comfortable with. None of this is complicated — it's mostly about knowing where things live.

## Why this matters now

Every ticket you'll work starts and ends in the same handful of tools. Get comfortable with them now, and your first real customer interaction is about the *customer*, not about hunting for which button does what.

## 🧰 What to get set up

- **Helpdesk / ticketing software** — this is where every support ticket lives, from the moment it's opened to the moment it's closed. Get access confirmed and spend a few minutes just clicking around before anything real is assigned to you.
- **Knowledge base** — the searchable library of articles both agents and customers use. Get read access early, and ask about write access once you're comfortable — you'll eventually be the one adding to it.
- **Screen sharing tools** — for seeing a customer's screen live instead of guessing from a written description. Some bugs are almost impossible to describe in words and completely obvious the second you actually see the screen. One courtesy rule that matters here: always ask before starting a session — it's someone else's screen.
- **Company chat tool** — for quick internal questions instead of firing off an email and waiting. Great for "hey, has anyone seen this error before?" type questions.

## 🏷️ What you'll be using

`Helpdesk Software` `Knowledge Base` `Screen Sharing` `Company Chat`

## 💡 Tips

- Spend time searching the knowledge base *before* you need it for a real ticket — knowing roughly what's in there is half the value.
- If you're not sure whether to start a screen share, just ask. Customers almost always say yes, and asking builds trust either way.
- Bookmark the helpdesk and the knowledge base now — you'll have both open all day, every day.
