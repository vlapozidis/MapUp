📊 With cloud fundamentals under your belt, it's time to zoom in on the part that's actually your job: **data**.

## Why this matters for a DBA

AZ-900 was about the cloud in general. DP-900 is about the world you'll live in every day — tables, queries, and the difference between "a database" and "a data warehouse."

## 🧠 What you'll learn

- **Core data concepts** — relational vs. non-relational data, and when to reach for each
- **Relational data on Azure** — Azure SQL Database, Azure SQL Managed Instance, and where they differ
- **Non-relational data on Azure** — Cosmos DB, Table Storage, and other NoSQL options
- **Analytics workloads** — a first look at how data gets turned into dashboards and reports

## 🏷️ Skills you'll pick up

`Relational Data` `Non-relational Data` `SQL Basics` `Azure SQL` `Cosmos DB`

## 📚 How to work through it

1. Open the **DP-900: Microsoft Azure Data Fundamentals** learning path on Microsoft Learn.
2. Pay extra attention to the relational vs. non-relational comparisons — this distinction comes up *constantly* in real DBA work.
3. If you've never written SQL before, don't panic. This path introduces it gently; the real practice comes next with some hands-on **T-SQL Fundamentals** on the roadmap.

## 💡 Tips

- It's fine if Cosmos DB feels abstract right now — most of your day-to-day will be relational (Azure SQL), but knowing NoSQL exists (and why teams choose it) makes you a much stronger DBA.
- Try to relate each concept back to something concrete: "a product catalog" for relational, "a shopping cart session" for NoSQL, for example.
